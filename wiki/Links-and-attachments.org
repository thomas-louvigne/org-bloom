* Links between pages

| Syntax                           | Leads to                                                 |
|----------------------------------+----------------------------------------------------------|
| =[[Page]]=                       | the page named /Page/ (Logseq wiki link)                 |
| =[[file:page.org]]=              | the page built from =page.org=                           |
| =[[file:page.org::*Headline]]=   | a headline of that page                                  |
| =[[file:page.org::target]]=      | the =<<target>>= of that page                            |
| =[[Page::*Headline]]=            | a headline of the page named /Page/ (Orgamnesia)         |
| =[[Page::target]]=               | the =<<target>>= of the page named /Page/ (Orgamnesia)   |
| =[[id:2f0c…][Label]]=            | the page or headline with that =:ID:= (org-roam)         |
| =[[*Headline]]=                  | a headline of the same page                              |
| =[[::target]]=                   | a =<<target>>= of the same page                          |
| =[[#custom-id]]=                 | the headline with that =:CUSTOM_ID:=                     |

* Links to a headline or a target

After =::= comes the place in the page, written as org-mode's search options:

- =*Headline=: the headline with that title. It is compared without its stars, TODO keyword, priority =[#A]=, statistics cookies =[1/3]= and tags, ignoring case and accents: =[[Recettes::*desserts]]= finds =** DONE Desserts [1/3] :sucre:=.
- =target=: the place where =<<target>>= is written in the page (it shows nothing on the site), or a radio target =<<<target>>>= (its text stays). Failing that, a headline with that title, as org-mode does.
- =#custom-id=: the headline with that =:CUSTOM_ID:=.

Without a label, =[[Recettes::*Desserts]]= reads /Recettes › Desserts/. When the place isn't in the page (any more), the link leads to the top of the page. =--check-links= reports the page when it doesn't exist, not a missing headline.

=--check-links= lists every internal link that would 404 — see [[Checks-and-tools][Checks and tools]].

* Logseq block references and embeds

Logseq points to a single block with its id: the block carries an =id= property, which Logseq adds the first time the block is referenced.

- Markdown page: an =id:: …= line under the bullet

  #+BEGIN_SRC markdown
  - Pâte brisée
    id:: 6a816381-5aa5-4e84-b4ab-7fa3581acd87
  #+END_SRC

- Org page: an =:id:= in the headline's drawer

  #+BEGIN_SRC org
  ,* Pâte brisée
  :PROPERTIES:
  :id: 6a816381-5aa5-4e84-b4ab-7fa3581acd87
  :END:
  #+END_SRC

| Syntax                                    | On the site                                                       |
|-------------------------------------------+-------------------------------------------------------------------|
| =((uuid))=                                | a link to the block, showing the block's first line (as Logseq does) |
| =[[((uuid))][label]]= (Org), =[label](((uuid)))= (Markdown) | a link to the block, showing /label/              |
| ={{embed ((uuid))}}=                      | the block and its children, in place of the bullet that holds it |
| ={{embed [[Page]]}}=                      | a link to the page, then all its blocks under it                  |

The link leads to the block in its page: the block's headline in an Org page, the bullet itself in a Markdown page. An embed must be alone in its bullet (=- {{embed …}}=, =** {{embed …}}=) and point to a page of the same format; otherwise it becomes a link. Embeds inside an embedded block are shown too, three levels deep at most, and a page embedding itself stops there.

Only published blocks are shown: a block of a private page, or under a =:noexport:= or =COMMENT= headline, is not found. Its =((uuid))= stays as it is and =--check-links= reports it. Block properties (=id::=, =collapsed::=…) are not shown on the site.

* Emacs equivalents

Emacs (org-mode, no extra package) has no block references; it links to a place and includes text at export:

| Logseq                  | org-mode                                                                 |
|-------------------------+--------------------------------------------------------------------------|
| =((uuid))=              | =[[id:uuid]]= (=:ID:= property, =org-id=), =[[file:page.org::*Headline]]=, =[[file:page.org::#custom-id]]=, =[[file:page.org::target]]= |
| ={{embed ((uuid))}}=    | =#+INCLUDE: "page.org::*Headline"= (=:only-contents t=, =:minlevel=, =:lines=), applied at export |

org-bloom follows all of these links (see the table at the top). =#+INCLUDE:= is not supported yet. The [[https://github.com/nobiot/org-transclusion][org-transclusion]] package shows included text live in Emacs, with =#+transclude: [[file:page.org::*Headline]]=.

* org-roam IDs

org-roam links by ID: =[[id:2f0c…][Label]]= leads to the page whose file-level =:PROPERTIES:= drawer has that =:ID:=, or to the headline whose drawer has it. An ID that matches no published page is reported by =--check-links= and its label shown as plain text.

* YouTube videos

A YouTube video is shown in the page, with its player, when it is written:

- Logseq style: ={{video https://www.youtube.com/watch?v=…}}= (or ={{youtube …}}=)
- Orgamnesia style: a bare link, =[[https://youtu.be/…]]=

A link with a label, =[[https://youtu.be/…][the talk]]=, stays a link. =youtube.com/watch=, =youtu.be=, =/shorts/=, =/live/= and =/embed/= addresses work, and so does a start time (=?t=90=, =&t=1m30s=): the video starts there.

The player is as wide as the text column. It comes from =youtube-nocookie.com=, YouTube's privacy-enhanced mode: no YouTube cookie is set until the reader presses play.

={{video …}}= with an address that is not YouTube (Vimeo…) becomes a plain link to it.

* Images and attachments

Images and attachments are copied into the site when a page links them:

- Logseq style: =[[../assets/file.pdf]]=
- org-mode style: =[[file:docs/guide.pdf]]=, files linked next to a page

=--check-assets= lists the assets that no page references.

* Image size and attributes

In org pages, the way Emacs shows an image (=#+ATTR_ORG:=) is used on the site too:

#+BEGIN_SRC org
,#+CAPTION: The garden in May
,#+ATTR_ORG: :width 600 :align center :alt A garden full of tulips
[[file:assets/garden.jpg]]
#+END_SRC

| =#+ATTR_ORG= option      | On the site                                                        |
|--------------------------+--------------------------------------------------------------------|
| =:width 600= or =600px=  | 600 pixels wide                                                    |
| =:width 50%=             | half the width of the text column                                  |
| =:width 0.5=             | same as =50%= (org's fraction of the width)                        |
| =:align center= / =right= | image centered / against the right edge (=left= is the default)    |
| =:background "#ffffff"=  | background color behind a transparent image (=t= adds nothing)     |
| =:alt Text=              | alternative text, read by screen readers and shown if it fails to load |
| =:title Text=            | tooltip on hover                                                   |
| =:height 300=            | height in pixels (with =:width=, the image may be distorted)       |
| =:class name=, =:id name= | HTML class and id, for your own CSS                                |
| =:style css=             | inline CSS, added to what =:align= and =:background= produce       |

Values may contain spaces: a value runs up to the next =:option=. Several options go on one line, as above. Options that only mean something to Emacs are ignored.

An image is never wider than the text column: a larger width is scaled down to fit, keeping its proportions. Without =:width=, an image shows at its natural size, within that same limit.

=#+ATTR_HTML:= works too, with any HTML attribute. For an option set in both, =#+ATTR_HTML= wins — use it to show an image differently on the site and in Emacs:

#+BEGIN_SRC org
,#+ATTR_ORG: :width 900
,#+ATTR_HTML: :width 400
[[file:assets/schema.png]]
#+END_SRC

=:align= and =:background= become a =style=, so an =#+ATTR_HTML: :style= on the same image replaces them.
