org-bloom is the new name of =logseq-site-builder=. What changed:

| Before                                         | Now                                                                       |
|------------------------------------------------+---------------------------------------------------------------------------|
| repository =thomas-louvigne/logseq-site-builder= | [[https://github.com/thomas-louvigne/org-bloom][thomas-louvigne/org-bloom]] (GitHub redirects the old URL) |
| =logseq-builder= command                       | =org-bloom=                                                               |
| =logseq-site-builder.toml=                     | =org-bloom.toml=                                                          |
| Python package =logseq_builder=                | =org_bloom=                                                               |

Your existing =logseq-site-builder.toml= keeps working: it is read whenever no =org-bloom.toml= sits next to it. Rename it to =org-bloom.toml= when convenient.

To swap the old command for the new one, run =pip uninstall logseq-site-builder= then =pip install -e .= from the repository.
