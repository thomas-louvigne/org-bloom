*The org-mode static website-builder. Bloom your personal wiki and/or blog with vanilla emacs, logseq, org-mode or Orgamnesia.*

📖 *Documentation: [[https://github.com/thomas-louvigne/org-bloom/wiki][the org-bloom wiki]]* (sources in [[file:wiki/Home.org][wiki/]])

* 🌸 org-bloom

org-bloom turns a folder of notes into a static website — HTML + CSS + vanilla JS, no server, no build framework. It reads Emacs org-mode folders, [[https://www.orgroam.com/][org-roam]] notes, [[https://logseq.com/][Logseq]] graphs (Org or Markdown) and [[https://github.com/thomas-louvigne/orgamnesia][Orgamnesia]] projects.

[[file:docs/themes.png]]

- wiki links, org links and org-roam IDs, images (sized and aligned with =#+ATTR_ORG=) and attachments
- blog and RSS from Logseq journals or org-roam dailies
- tags, readable dates, authors
- private notes with =#+PUBLIC= and =:noexport:=
- themes (=default=, =dark=, =nord= or your own CSS), tree view, share & print bar
- client-side full-text search

Example: [[https://chroniques-insoumises.com/][chroniques-insoumises.com]], a Logseq knowledge base built with the =nord= theme.

* Quick start

Requires Python 3.11+, [[https://pandoc.org/installing.html][pandoc]] 3.8 or later (a separate program, checked at startup) and git. The Python libraries (click, pypandoc, jinja2, beautifulsoup4) are installed automatically.

#+BEGIN_SRC bash
sudo pacman -S --needed python pandoc-cli git    # Arch Linux
sudo apt install python3 python3-venv git        # Debian/Ubuntu (+ pandoc ≥ 3.8 from https://github.com/jgm/pandoc/releases)
brew install python pandoc git                   # macOS
#+END_SRC

*Try it in one line* — builds a sample Logseq graph shipped with the repository (Org and Markdown pages, journals turned into a blog, a private draft left out) and opens it in your browser:

#+BEGIN_SRC bash
git clone https://github.com/thomas-louvigne/org-bloom.git && org-bloom/org-bloom demo
#+END_SRC

=org-bloom/org-bloom= is a launcher: its first run installs org-bloom into =org-bloom/.venv= (nothing outside the clone), then it takes the same arguments as the installed command — =org-bloom/org-bloom ~/my-notes ~/Sites/my-site=. Set =PORT= to serve the demo on another port than 8080. =test-sites/= also holds two more Logseq graphs (=dark= and =nord= themes) and an org-roam garden (=04-org-roam-jardin=).

*Install the command* so that =org-bloom= works from anywhere, with [[https://pipx.pypa.io/][pipx]] (=python-pipx= on Arch, =pipx= on Debian/Ubuntu and Homebrew):

#+BEGIN_SRC bash
pipx ensurepath          # once, then open a new terminal
pipx install -e ./org-bloom
#+END_SRC

=pip install --user= fails on recent Linux distributions (=externally-managed-environment=) — see [[https://github.com/thomas-louvigne/org-bloom/wiki/Installation][Installation]] for the alternatives and the development setup.

*Then on your own notes* — two org files are enough:

#+BEGIN_SRC bash
mkdir -p ~/bloom-notes
cat > ~/bloom-notes/index.org <<'EOF'
,#+TITLE: Home

Hello! Read [[file:first-note.org][my first note]].
EOF
cat > ~/bloom-notes/first-note.org <<'EOF'
,#+TITLE: My first note
,#+FILETAGS: :demo:

Written in /org-mode/, published by org-bloom.
EOF
org-bloom ~/bloom-notes /tmp/bloom-notes-site
#+END_SRC

⚠️ The output folder is *wiped* before every build. The first build creates =org-bloom.toml= in your notes folder: every option is in [[file:org-bloom.example.toml][org-bloom.example.toml]] and in the [[https://github.com/thomas-louvigne/org-bloom/wiki/Configuration][Configuration]] page of the wiki.
